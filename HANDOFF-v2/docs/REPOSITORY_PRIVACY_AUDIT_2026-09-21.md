## Что остаётся в старой истории Git

Старые коммиты всё ещё содержат фотографии автомобилей, прежние варианты личных
идентификаторов и просроченный токен. Закрытие репозитория и новый коммит старую
историю не переписывают.

Удаление этих данных из истории потребует переписать коммиты и сделать force-push.
Это разрушительная операция для существующих копий репозитория, поэтому её нельзя
выполнять автоматически. Если репозиторием пользуется только владелец, можно
отдельно согласовать очистку истории. Просроченный токен использовать нельзя в
любом случае; при сомнении активные сессии OpenAI следует отозвать в аккаунте.
