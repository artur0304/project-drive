# Сюда складывать новые фотографии машин

Просто скопируй сюда JPG, PNG, WEBP или HEIC. Для особых ракурсов добавь в имя
одно слово: `shadow` (машина в тени), `rear` (вид сзади) или `wheel-closeup`
(диски видны крупно). Например: `range-rover-rear.jpg`.

Проверка ничего не загружает в интернет и не вызывает AI:

```powershell
npm --prefix HANDOFF-v2/ai-core-slice0 run photos:check
```
